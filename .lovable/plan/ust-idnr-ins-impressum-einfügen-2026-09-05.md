# USt-IdNr. ins Impressum einfügen

## Ziel
Die Umsatzsteuer-Identifikationsnummer **DE301128879** soll im Impressum unter einem eigenen Abschnitt ausgewiesen werden.

## Vorgehen
1. `src/routes/impressum.tsx` öffnen.
2. Nach dem Abschnitt „Registereintrag" einen neuen Abschnitt „Umsatzsteuer-Identifikationsnummer" einfügen und die Nummer **DE301128879** anzeigen.
3. Build mit `bun run build` prüfen.

## Technische Details
- Betroffene Datei: `src/routes/impressum.tsx`
- Keine neuen Abhängigkeiten, keine Backend-Änderungen.
